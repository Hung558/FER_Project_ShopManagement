# FER202 Project

React app (Create React App) using React Router, React Bootstrap, Axios, and json-server.

## Setup

```bash
npm install
```

## Run

```bash
npm start
```

Opens at http://localhost:3000.

Mock API (if you have a `database.json`):

```bash
npx json-server database.json --port 9999
```

## Scripts

| Command         | Purpose                  |
|-----------------|--------------------------|
| `npm start`     | Dev server               |
| `npm run build` | Production build (`/build`) |
| `npm test`      | Run tests                |
